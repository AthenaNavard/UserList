# 👥 User List (CRUD)

A simple user management app built with **React** and **Vite**, featuring a raw **Brutalism** UI style.

## ✨ Features

- Fetches initial user data from a public API.
- Add new users (Name & Email) via a simple form.
- Delete users instantly from the list.
- Fully responsive design.
- High-contrast Brutalism styling (thick borders, hard shadows).

## 🛠️ Technologies Used

- **React** (Hooks: `useState`, `useEffect`)
- **CSS** (Brutalism style)
- **Fetch API**

## 🚀 How to Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## 📡 API Used

- [JSONPlaceholder](https://jsonplaceholder.typicode.com/users) - Fake user data.
